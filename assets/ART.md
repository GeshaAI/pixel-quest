# PIXEL QUEST v0.7 art

These four original artwork files were created for PIXEL QUEST using the built-in
image-generation tool. No paid API is used by the game. WebP encoding keeps the
original output resolution and alpha. Terrain and pose regions are sampled from
the atlases by Canvas; images remain separate from gameplay collision shapes.

- forest-day.webp: rich original 16-bit woodland valley, ancient oak trees, distant
  misty mountains, river and ruined tower; side-on, quiet bottom meadow; no game
  objects, characters, UI or text.
- forest-dusk.webp: edit of the day scene, preserving landscape and composition,
  with indigo dusk, crescent moon, river reflections and restrained fireflies.
- scout-atlas.webp: transparent 4x2 grid of the same teal-clad original explorer
  with brass goggles, orange scarf, backpack and leather boots; idle, run poses,
  jump, fall and victory.
- world-atlas.webp: 3x2 grid with grass/earth, deep soil, mossy sandstone platform,
  bronze-cornered bonus crate, amber gem and purple forest beetle.

Direction: handcrafted detailed pixel art, turquoise shadow/amber light palette,
crisp intentional clusters, original indie fantasy, no Nintendo elements.

## v0.8.0 resources
- crystal-cave.webp: original detailed pixel-art panorama, 2172×724; blue/violet
  crystal cavern, underground river, stone arches, distant ruined bridge and amber
  lanterns. Quiet lower band, side-on perspective; no foreground platforms,
  characters, text or HUD. Produced with the built-in image generator.
- bat-atlas.webp: original transparent 2×2 flight-pose atlas, 1254×1254. One same
  violet bat with amber eyes, turquoise crystal forehead and teal/violet wings;
  raised/spread/down/half-raised wing poses, no captions or scene. Generated with
  the built-in image generator; sampled by explicit source rectangles.

The images retain their original resolution and transparency and are encoded
as WebP for browser delivery. Prompts requested the approved detailed fantasy
pixel-art direction, cool indigo shadows, cyan light and restrained amber highlights.
