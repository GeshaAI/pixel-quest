# PIXEL QUEST — вертикальное приключение

Продолжай существующий проект https://github.com/GeshaAI/pixel-quest. Сначала изучи main, историю, файлы и тесты. Сохрани оригинального героя, утверждённую графику, старые уровни и совместимость сохранений. Для крупных изменений создай отдельную ветку и Pull Request.

Цель: развить игру в приключенческий платформер с маршрутами вправо и вверх. Используй общие принципы классических платформеров, но создавай собственные уровни, изображения, названия и звуки.

Первый выпуск — v0.9.0, четвёртый уровень «Древесная башня»:
- Вертикальная камера с плавным сопровождением героя.
- Деревянные площадки среди огромных деревьев, читаемый путь к вершине.
- Движущаяся платформа-лифт, которая переносит героя без проскальзывания.
- Канаты: захват, подъём, спуск и прыжок с отпусканием.
- Лиана: захват, раскачивание влево/вправо и прыжок с сохранением части импульса.
- Монеты, патрулирующие противники, контрольная точка на высоте, скрытый карман с наградой и финиш наверху.
- Сенсорные кнопки движения слева, прыжка и действия справа; вверх/вниз для лазания. Одновременные касания, отмена ввода при паузе. Клавиатура: A/D или стрелки, Space, W/S, Shift/E.
- Первые препятствия учат механике, следующие соединяют её с уже знакомыми действиями. Не требуй освоить всё одновременно.

Технические условия: HTML5, Canvas 2D, JavaScript, Web Audio; без внешнего сервера, обязательной регистрации и платных ресурсов. Физика с фиксированным шагом, ограничение времени кадра, отсечение невидимых объектов. Платформы не должны проталкивать героя через геометрию. Сохранение контрольной точки учитывает обе координаты.

Порядок: сначала полностью проходимая башня и проверки новых механик; затем улучшение анимаций и оформление. Пружины, обрушивающиеся площадки, новые миры и боссы — следующие этапы, не объявляй их готовыми заранее.

Проверки: регрессии старых уровней и сохранений; прохождение башни командами движения без телепортации; перенос на лифте; прыжок с каната; захват и отпускание лианы; восстановление высоты после урона и перезагрузки; финиш только на вершине. Запусти доступные тесты, исправь ошибки и укажи фактические результаты. Не обещай 60 FPS и не утверждай, что проверил Samsung SM-P610, без реального теста пользователя.

Публикация: обнови версию, документацию и GitHub Pages. Согласуй версию Android-оболочки с игрой; прежний скачанный APK сам не обновляется. В отчёте дай ссылку, управление и перечень ограничений.
